# KABAN-SISTEMA-DE-AGENDAMENTO-DE-CONSULTAS

https://trello.com/invite/b/6aa09796a794d320911f02d6/ATTId2063fd59ad51ecd2c99c3a50d34728cF292955F/kaban

O cenário utilizado é um **sistema web de agendamento para uma clínica**.

Serviço de desenvolvimento e manutenção de um sistema web de agendamento para clínica, responsável por tratar funcionalidades, correções de defeitos e melhorias técnicas, acompanhando as demandas desde a solicitação até a entrega.
O objetivo da atividade é representar e simular o fluxo de trabalho de uma equipe utilizando o método Kanban.


## Quadro Kanban

O fluxo foi dividido nas seguintes etapas:

- Solicitado
- Pronto para desenvolver
- Em desenvolvimento
- Revisão
- Testes
- Entregue

## Limites de WIP

Foram definidos limites para controlar a quantidade de tarefas em andamento:

- Em desenvolvimento: **3**
- Revisão: **2**
- Testes: **2**

Os limites ajudam a evitar o acúmulo de tarefas e facilitam a identificação de gargalos.

## Tipos de trabalho

Os cartões foram classificados em:

- Funcionalidades
- Defeitos
- Melhorias técnicas

Também foi utilizado um cartão bloqueado para representar um impedimento no fluxo.

## Políticas do quadro

1. Uma nova tarefa só pode ser puxada quando houver capacidade.
2. Os limites de WIP devem ser respeitados.
3. Itens bloqueados não podem avançar até que o impedimento seja resolvido.
4. Uma tarefa só pode ir para Testes depois de passar pela Revisão.
5. Uma tarefa só é considerada entregue após concluir os testes.
